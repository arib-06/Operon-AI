> **Empowering Saudi Arabia's Vision 2030 through AI-Driven Renewable Resilience.**

Developed for the **KFUPM Venture Craft Hackathon**, Operon AI is a cutting-edge autonomous operations platform designed to solve the most critical challenge for solar energy in the Middle East: **The Desert Environment.**

---

## 🌟 The Vision

In the heart of the Saudi desert, solar panels face a relentless battle against fine silica dust and extreme thermal saturation. Traditional fixed cleaning schedules are inefficient—either cleaning too often and wasting water/energy, or cleaning too late and losing millions in potential generation.

**Operon AI** shifts the paradigm from *Reactive Maintenance* to **Autonomous Intelligence**. It monitors, predicts, and dispatches cleaning drones or robotic fleets only when the financial ROI makes sense, ensuring maximum efficiency for the Kingdom's mega-projects like NEOM, Sakaka, and Sudair.

---

## 🚀 Core Pillars

### 📡 1. Command (Strategic Intelligence)
*   **AI Autonomous Operator**: A real-time decision engine that simulates telemetry (Dust, Temperature, kW) and automatically determines the most profitable intervention vector.
*   **Financial ROI Calculator**: A high-fidelity simulator for plant managers to project 5-year revenue gains by switching from manual schedules to Operon's dynamic dispatch.

### 🔍 2. Analysis (Deep Visibility)
*   **Digital Twin (Sakaka Array)**: A geospatial 3D twin of the Sakaka solar project, providing node-level stress analysis, thermal load monitoring, and future capacity simulation.
*   **Geospatial Intel**: A country-wide threat map tracking dust storms, thermal hotspots, and humidity risks across NEOM, Tabuk, Riyadh, and Al Jawf.
*   **Augmented Knowledge Graph**: An AR-style network visualization showing the complex interconnections between sensors, inverters, and the core AI engine.

### 🏗️ 3. Infrastructure (Robust Operations)
*   **Telemetry Data Lake**: A massive ingestion hub processing billions of records via MQTT and Modbus TCP, with integrated cost-per-query analysis.
*   **Mission Control Panel**: Real-time service health monitoring, CPU/latency tracking, and infrastructure orchestration.
*   **Security & Governance**: Advanced threat intelligence monitoring for physical (unidentified drones) and digital (DDoS, PLC exploits) risks to national energy infrastructure.

## 🛠️ Getting Started

### Prerequisites
*   Node.js 20+
*   npm / yarn / pnpm / bun

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-repo/operon.git
    cd operon
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Open the dashboard**:
    Navigate to [http://localhost:3000](http://localhost:3000) to view the Autonomous Operator.
